# 4層stackupと差動ペアのfixture

このfixtureは、4層基板のstackup宣言とUSB差動ペアのインピーダンス契約を
最小構成で検証する。`F.Cu`を配線層、直下の`In1.Cu`を平面参照層とし、
IPC-2141のmicrostrip近似へ次の値を入力する。

- 誘電率 `er=4.0`
- 参照層までの誘電体厚 `h=0.1 mm`
- 配線幅 `w=0.15 mm`
- 銅厚 `t=0.035 mm`
- 差動gap `s=0.15 mm`

計算された差動インピーダンスは約`89.517 Ω`であり、目標`90 Ω`、許容差`10 %`
以内である。IPC-2141式はfield solverではないため、実測Evidenceをauthoritativeな
判定入力とし、この計算結果だけを実測の代替にはしない。
