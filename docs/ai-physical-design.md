# AI主導の配置・回転・配線探索

> ステータス: Draft

配置・回転・配線は、LLMの提案と決定論的な探索・判定を分離する。LLMはモジュール分解、
相対配置制約、優先度、回転方針、探索戦略を自然言語で提案できるが、座標・回転角の値を
直接出力しない。候補生成と幾何整合化はスクリプトが行う。

## 探索手順

1. LLMが設計意図と探索方針を提案する。
2. 決定論的探索器が候補を生成し、courtyard、keepout、外形、回転制約を検査する。
3. HPWLや混雑度などの代理指標で候補を順位付けする。
4. 外部router、DRC/ERC、Gerber独立parser再読込などの高価な実測を少数候補へ行う。

代理指標は順位付けだけに使い、合格根拠にしない。LLMを探索の内側ループへ呼び戻さない。
回転刻みの安全境界は`profiles/`の版管理設定で変更する。

## レビュー

機械可読投影と視覚投影を生成し、subagentとvisionへ渡す。所見は自然文で修正ループへ返す。
LLMレビュー、goal判定、探索の成功状態は合否権限を持たず、決定論的ゲートだけが合否を決める。

## 停止条件

ツール不在、parse失敗、ゲート未実行、安全境界の`unknown`は停止する。候補生成・整合化・
実測のいずれかが不明な場合も、合格として扱わない。
