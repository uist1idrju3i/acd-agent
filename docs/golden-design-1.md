# Golden Design #1

> ステータス: Draft  
> 対象: 趣味・研究・小規模試作の第1マイルストーン
> 対象工程: `S1`、`E1`、`E2`、`S2`

本書は、基板とFWで実機LEDを点灯する最小のgolden task入力を定める。入力ファイルとgitを
正とし、Pydantic契約、生成スクリプト、独立parser、決定論的ゲートを使う。

## 入力

- 部品MPN、ライブラリ、footprint、3D modelの出所。
- ネット一覧、ピン割当、電源条件、アンテナkeepout。
- 2層FR-4基板、外形、部品配置、製造条件。
- ESP-IDFの版、FW入力、期待するLEDとシリアルログ。

## 工程と成果物

| 工程 | 成果物 |
|---|---|
| `S1` | 要件と安全境界 |
| `E1` | 部品、回路、ネット、ピン割当 |
| `E2` | PCB、配置、配線、Gerber/drill |
| `S2` | BOM、CPL、FWパッケージ、実機テスト項目 |

## ゲート

- ERC/DRCを実行する。
- Gerber、drill、BOM、CPLを独立parserで再読込する。
- FWをビルドし、静的解析、単体テスト、ピン割当整合、期待ログを検査する。
- 価格・在庫は発注直前に確認し、上限額以内で全ゲートを通過した場合だけ発注する。
- ツール不在、parse失敗、ゲート未実行、安全境界の`unknown`は停止する。

## 負の試験

故意にネット、ピン割当、keepout、出力形式を変更し、独立parserまたは決定論的ゲートが
合格を返さず停止することを確認する。
