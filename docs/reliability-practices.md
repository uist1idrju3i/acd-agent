# 信頼性・安全性プラクティス

> ステータス: Draft

本書は、将来の高信頼化のための調査記録であり、現在のACD規範ではない。宇宙・安全重要用途の
要求を現在の小規模試作へ導入するものではない。

## 調査対象

- 部品、材料、製造能力、測定器の出所と確認方法。
- 外部ツールの版固定、設定、再現可能な入力と出力。
- ERC/DRC、干渉、独立parser再読込、FW検査の独立性。
- 実機測定と失敗した試作を次の入力へ反映する方法。

## 現在の境界

現在の合否は決定論的ゲートだけで決める。ツール不在、parse失敗、ゲート未実行、安全境界の
`unknown`は停止する。高度な安全解析、認証、構造化レビュー、追加承認は本リポジトリの要求ではない。
