# ECAD領域メモ

> ステータス: Draft

本書は、ECAD adapterとパイプラインが扱う入力・出力の注意点をまとめる。入力ファイルとgitを
正とし、生成物は独立parserで再読込する。

## 形式と幾何

- 原点、単位、軸、面、回転基準を入力ファイルへ明示する。
- footprint、symbol、3D modelの出所と版を記録する。
- variant／DNP、netclass、rule area、stackupを生成スクリプトで整合させる。
- courtyard、keepout、外形、肉厚、穴、アニュラリングを独立に検査する。
- ゾーンやratsnestなどの派生状態は、検査前にツールで再計算する。

## 製造出力

Gerber、drill、BOM、CPL、STEP/3MFは形式と単位を固定し、独立parserで再読込する。
部品番号、ピン割当、座標、原点、回転を照合する。生成側の自己申告だけで合格にしない。

## 外部ツール

adapterはツール名、版、入力hash、出力hash、収束状態、実行時刻を記録する。ツール不在、
版不明、parse失敗、期待形式でない出力、未収束は停止する。設定ディレクトリは工程ごとに
明示し、ワークツリー操作と外部ツール実行を同時に行わない。

## ルール

ERC/DRCと干渉検査は決定論的ゲートである。LLMレビュー、ライブラリ記述、代理指標、
自然文の説明は合格根拠ではない。修正後は入力ファイルをgitへ記録し、全ゲートを再実行する。
