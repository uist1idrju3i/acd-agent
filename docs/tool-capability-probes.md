# 外部ツール能力プローブ

> ステータス: Draft

外部ツールの不在、版不明、parse失敗、非決定性を事前に調べる。結果はツール名、版、入力hash、
出力hash、収束状態、実行時刻とともにgit管理の記録へ残す。不明な能力を合格としない。

## 対象

| 分野 | 例 |
|---|---|
| ECAD | KiCad CLI、Gerber/drill parser、router |
| MCAD | CAD kernel、STEP/3MF parser、slicer |
| FW | compiler、静的解析、単体テスト、仮想実機 |
| 製造 | fab形式、価格・在庫API、製造能力 |

## プローブ項目

- 実行ファイルの存在と版。
- 設定ディレクトリを指定した再現可能な実行。
- 入力ファイルのparseと期待形式での出力。
- 同一入力を再実行した出力の再読込。
- ERC/DRC、geometry、干渉、ピン割当などの検査能力。
- ツール不在、版不明、非収束、parse失敗時の停止動作。

## 実行

実装されたプローブは`uv run python scripts/probe_tools.py`から実行する。プローブの成功状態
だけで合格にせず、各工程の決定論的ゲートを別に実行する。能力が不足する工程は停止し、
代替ツールの採用は入力ファイルとgitへ記録する。
