# ライブラリと実測のメモ

> ステータス: Draft

本書は、次の設計で再利用するためのライブラリ出所、製造能力、測定値のメモである。
入力ファイルとgitが正であり、本書やSkillの記述を設計や合否の正にしない。

## 記録するもの

- 部品、footprint、3Dモデル、回路記号の出所と確認日。
- fabの材料、形式、製造能力、価格、在庫、製造条件の出所。
- 外部ツール名・版、形式版、入力hash、出力hash、実行時刻。
- 実機の測定値、使用した測定器、条件、対象部品。
- 失敗した試作と、その修正に使った入力ファイルのcommit。

## SDK資材

Skill、plugin、`AgentDefinition`は作業手順とレビュー観点を配布する資材であり、設計の正ではない。
会話履歴とSDKのcheckpoint／resumeは作業を継続するために使う。投影は入力ファイルへ逆流させず、
修正はファイルを編集してgitへ記録する。

## ライブラリと製造データ

公式ライブラリを直接改変せず、必要な差分はプロジェクト内のadapterまたは生成スクリプトで
明示する。BOM、CPL、Gerber、drill、STEP/3MFは独立parserで再読込し、座標、単位、原点、
回転、部品番号、ピン割当を検査する。

## 実機フィードバック

実機の所見は自然文のレビュー材料として次の修正を決めるために使う。再現に必要な条件と
測定値を入力ファイルまたはgit管理の記録へ残し、LLMの説明だけで合格にしない。
